**Translator** 一个小巧的桌面翻译工具。

## 用法

需要先注册一个在线翻译服务

目前已接入百度翻译：[fanyi-api.baidu.com](https://fanyi-api.baidu.com/)

注册完成后把得到的 `APP ID` 和 `API Key` 设置到本应用中。

如下图所示：

<img alt="支付宝赞助" src="./Doc/apiWin.png" width="520" height="430">

之后，当你选中文本后，按下 `Ctrl+Alt+T` 即可得到翻译结果（你可以在设置界面修改快捷键）。

<img src="./Doc/resultWin.png" width="390" height="257">

程序会自动识别你选中的文本，

如果你选中的文本中包含中文字符，则会翻译成英文，

如果你选中的文本中没有中文字符，则会翻译成中文。
